第一步：开发环境准备 (Setup)
在你开始写任何代码之前，需要先准备好“纸和笔”。

下载安装 Android Studio：这是安卓开发的官方IDE（集成开发环境），用于创建项目、运行和调试应用。

下载安装 Cursor：这是你的AI编程助手，将负责生成绝大部分的代码。

创建项目：用Android Studio创建一个新项目，建议选择 “Empty Views Activity” 模板。技术栈推荐使用 Kotlin 语言和 Jetpack Compose 来构建界面。

用Cursor打开项目：关闭Android Studio，然后用Cursor打开刚才创建的项目文件夹。

🧠 第二步：项目规则设定 (Set Rules)
在开始编码前，先给Cursor设定好“行为准则”，这能让它更好地理解你的项目。

在项目根目录下新建一个 .cursorrules 文件，在里面写下类似这样的内容：

markdown
# 项目：热干面传奇 (Reganmian Legend)
# 技术栈：Kotlin, Jetpack Compose, Material 3
# 架构：MVVM (Model-View-ViewModel)

## 角色
你是一个资深Android开发专家，精通Kotlin和Jetpack Compose。

## 目标
帮助我开发一款名为“热干面传奇”的模拟经营游戏。

## 游戏核心机制
玩家扮演热干面店老板，通过点击操作完成“煮面、掸面、调酱、烫面、加料、出餐”等一系列步骤，满足顾客需求以赚取金币。

## 编码要求
1.  所有UI代码必须使用Jetpack Compose编写。
2.  状态管理推荐使用StateFlow或MutableState。
3.  代码要清晰、规范，并添加必要的注释。
4.  在生成代码前，先简要说明你的实现思路。
📝 第三步：梳理游戏需求与设计 (Plan & Design)
这个阶段不写代码，而是用Cursor的 Plan 模式 把游戏想清楚。

提示词示例：

“我要开发一个类似《沙威玛传奇》的安卓模拟经营游戏，名字叫《热干面传奇》。请帮我梳理一份详细的游戏设计文档（GDD）。文档需要包含：

核心玩法：将《沙威玛传奇》的制作流程（切肉、炸薯条、卷饼）替换为武汉热干面的制作流程。热干面的关键步骤包括：掸面（煮面、拌油、吹凉）、调制芝麻酱、烫面、加配料（辣萝卜丁、葱花等）和出餐。

游戏机制：顾客点单、满意度系统、金币收益、设备升级（例如：升级煮面锅、自动掸面机）、新角色解锁（如小偷、乞丐）。

UI/UX设计：手绘卡通风格，主界面为热干面操作台，有各个原料和操作按钮。

技术实现：使用Kotlin和Jetpack Compose，请给出大致的页面结构和状态管理方案。”

🚀 第四步：核心功能迭代开发 (Develop)
这是最关键的环节。不要想着一次性完成所有功能，而是一个个来，遵循 “Cursor写代码 -> Android Studio测试 -> 反馈修改” 的循环。

你可以使用Cursor的 Agent 模式，它能自主阅读你的整个项目代码，生成或修改多个文件。

阶段一：实现静态UI (Static UI)
先用代码把游戏界面“画”出来，先不用管逻辑。

提示词示例：

“请帮我在 MainActivity.kt 中，使用Jetpack Compose构建游戏主界面的静态布局。
界面布局参考如下：

顶部是顾客区域：显示顾客头像、需求（如“要一份热干面，多放辣”）和满意度进度条。

中间是操作台区域：水平排列几个核心操作按钮，比如一个‘煮面锅’、一个‘酱料碗’、一个‘配料台’。

底部是信息栏：显示当前金币数量和已完成的订单数。
请使用 Column 和 Row 进行布局，并用 Button 或 Image 来代表各个操作点。”

阶段二：实现核心游戏循环 (Core Loop)
这是游戏“好不好玩”的根本。实现从“点击操作”到“完成订单”的完整流程。

提示词示例：

“现在开始实现游戏的核心逻辑，即‘热干面制作流程’。我需要一个 GameViewModel 来管理游戏状态。

定义状态：创建 GameState 数据类，包含 doughState (生面/煮熟/拌油/掸好), sauceState (未调/已调), toppings (List<String>), currentOrder (Order?), goldCoins (Int) 等。
实现步骤：
点击‘煮面锅’：将 doughState 从‘生面’变为‘煮熟’。
点击‘掸面’按钮：将 doughState 从‘煮熟’变为‘掸好’。
点击‘酱料碗’：将 sauceState 从‘未调’变为‘已调’。
点击‘配料’：将选择的配料（如辣萝卜丁）添加到 toppings 列表中。
点击‘出餐’按钮：检查所有状态是否满足订单要求，若满足则完成订单，增加金币并生成新订单；若不满足则提示玩家。”
请使用 StateFlow 来暴露这些状态，并在 Compose 中收集它们来更新UI。”
阶段三：添加游戏机制与润色 (Polish)
核心玩法打通后，就可以加入更多元素来丰富游戏了。

提示词示例：

“游戏已经可以运行了，现在我们来增加一些让游戏更有趣的机制：

顾客系统：实现不同顾客类型，他们会有不同的要求（如‘不要葱’、‘加辣’）和耐心值。耐心值归零顾客会离开。
升级系统：设计一个商店页面，玩家可以用金币升级设备。例如，升级‘煮面锅’可以加快煮面速度，升级‘酱料台’可以自动调酱。
特殊事件：添加‘小偷’和‘乞丐’事件。乞丐会索要一碗面，而小偷会偷走柜台上的金币，玩家需要点击他们来应对。
游戏结束条件：设定游戏目标，比如在限定天数内赚取足够金币升级店铺即可通关。”
注：你可以分多次对话，每次只让Cursor实现其中一个功能点。
✨ 第五步：测试、调试与优化 (Test, Debug & Optimize)
这是保证游戏质量的关键一步。务必在Android Studio中运行和测试。

测试：运行应用，模拟玩家操作，检查每一步逻辑是否正确。

调试：如果应用崩溃或功能异常，直接把Android Studio的错误日志或截图粘贴到Cursor的对话框中。Cursor能帮你分析问题并给出修复代码。

优化：感觉游戏卡顿或操作不流畅？可以让Cursor帮你分析和优化代码性能。

💡 一些额外的小建议
利用好 @ 符号：在Cursor的对话中，使用 @ 可以引用特定文件或整个代码库 (@codebase)，让AI的回答更精准。

善用 .cursorrules：在开发过程中，如果发现Cursor总是不按你的想法来，可以随时更新这个文件，给它更明确的指令。

发挥创意：除了核心玩法，你还可以让Cursor帮你：

生成美术素材：描述你想要的风格，让它提供设计建议或生成 SVG 代码。

添加音效：让它帮你写一段播放音效的代码，让游戏更生动。

完善细节：比如为热干面增加“酸豆角”、“香菜”等更多配料选项。

你的想法很棒，将一个全球化的玩法框架与地道的地方美食文化相结合，本身就很有潜力。希望这份规划能帮助你顺利地启动“热干面传奇”的开发。如果在某个具体环节卡住了，随时可以再来问我。祝你开发顺利！
